# Group Hold: friend side (prototype)

A design-concept prototype for the friend's side of **Group Hold**, a group seat-hold feature for a movie-booking app. Made by Shrestha Sharma (23B3629, IIT Bombay) for a 48-hour Navi design challenge.

A friend opens the booker's WhatsApp link, sees the booking details, and either pays their own share now or chooses to pay later and gets reminders.

## Run it
Open `index.html` in any browser. It is one self-contained file. No real payment is taken.

Use the "Demo states" link under the phone to jump to states such as hold ended, cancelled, all seats taken, payment failed and last 10 minutes.

The booker side lives in the companion repo: navi-design-task-bms-group-hold.
